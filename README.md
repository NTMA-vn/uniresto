## 🛠 Stack Technique Imposée
- **Backend :** Symfony (PHP 8.2+) / Doctrine ORM (Architecture locale sans API/Cloud externe)
- **Frontend :** Angular (TypeScript)
- **SGBD :** MySQL / PostgreSQL
- **Gestion de projet :** Jira & Git

## 🎯 Problème Algorithmique Étudié
Optimisation du plan de production et d'approvisionnement limitant le gaspillage et les coûts sous contraintes de péremption, de capacités et de budget.
- **Méthode 1 :** Heuristique Gloutonne FEFO (First Expired, First Out)
- **Méthode 2 :** Métaheuristique (Recuit Simulé)
